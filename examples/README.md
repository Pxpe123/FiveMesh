# Examples

This folder is for curated demo assets used by the hosted FiveMesh app.

Add model files under `examples/assets`, then list them in `examples.json`.
For example:

```text
examples/
|-- examples.json
`-- assets/
    `-- baller/
        |-- Baller.yft
        `-- Baller.ytd
```

Only add files you are comfortable hosting in the public app.
